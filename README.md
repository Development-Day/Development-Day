## 🧭 Как присоединиться

</div>

<table align="center">
<tr>
<td align="center" width="25%">

**1️⃣ Выбери проект**

Найди проект в списке выше или предложи идею в [Issues](https://github.com/Development-Day/Development-Day/issues).

</td>
<td align="center" width="25%">

**2️⃣ Сделай fork**

Создай ветку и внеси изменения — даже если это первая правка.

</td>
<td align="center" width="25%">

**3️⃣ Отправь PR**

Pull request с описанием изменений. Ревью поможем пройти.

</td>
<td align="center" width="25%">

**4️⃣ Обсуждай**

Присоединяйся к [Discussions](https://github.com/Development-Day/Development-Day/discussions).

</td>
